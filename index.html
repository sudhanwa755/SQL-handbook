SQL Command Categories Matrix

Core syntax categories, transactional controls, and definition languages. Click any chip to copy.

DDL Structure
Data Definition Language
Defines, modifies, and alters the physical structure and metadata of relational database objects.
CREATE ALTER DROP TRUNCATE
DML Data Rows
Data Manipulation Language
Manipulates the actual rows and values stored inside existing database tables.
INSERT UPDATE DELETE
DQL Retrieval
Data Query Language
Queries, filters, joins, aggregates, and retrieves record sets from one or multiple tables.
SELECT
TCL Transaction
Transaction Control Language
Maintains atomic transactions, rollbacks, and points of recovery for data integrity.
COMMIT ROLLBACK SAVEPOINT
DCL Security
Data Control Language
Controls authorization, role assignments, grants, and security privileges on database entities.
GRANT REVOKE
