⚡ Quick Reference — SQL Command Categories

Category Full Name Commands Purpose
DDL Data Definition Language CREATE, ALTER, DROP, TRUNCATE Define or modify database structure
DML Data Manipulation Language INSERT, UPDATE, DELETE Manipulate the data inside tables
DQL Data Query Language SELECT Retrieve data from tables
TCL Transaction Control Language COMMIT, ROLLBACK, SAVEPOINT Control the outcome of transactions
DCL Data Control Language GRANT, REVOKE Manage permissions and access
